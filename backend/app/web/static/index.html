What this does

Instead of generic video-editing advice, Reel Intelligence decodes the reels that already work for your page into a concrete, checkable rule set — hook, pacing, storytelling, audio, visual style — then checks any new reel against those exact rules, so you know precisely why it's likely to under- or over-perform before (or after) you post it.

How it works
  1. Create a Project from a handful of reels that already performed well — a retention-graph recording per reel is optional but helps.
  2. We decode the pattern across those reels — hook, pacing, storytelling, audio, visual style — into a small set of concrete, checkable rules, not generic advice.
  3. Test any reel against that project's rules to see exactly what's working, what isn't, and why — with or without a retention graph for the reel being tested.

When provided, adds a second-by-second drop analysis on top of the rule-based critique. Without it, you still get a full critique based on this reel's own stats and engagement vs. the project's benchmark — just not tied to exact moments.
How to record a retention graph (with an example)
  1. Open the reel in the Instagram Edits app (not the main Instagram app) → Insights → tap the retention graph.
  2. Start a screen recording, then slowly drag your finger left to right across the graph, pausing briefly every second or so — each pause gives a clean, readable "X% at 0:0Y" tooltip.
  3. Keep the recording tight on the graph itself (not the whole phone screen with extra chrome) — like the example below.
  4. Upload the resulting video. No need to trim it.
